# Onyx Nibble

Full-colour Python 3 neon snake arcade for ElbowOS.

Steer a glowing onyx serpent across a neon grid. Nibble cyan, magenta and gold orbs to grow and score. Wrap the edges, avoid biting yourself.

## Play

```bash
pip install -r requirements.txt
python3 onyx_nibble.py --play
```

Arrows / WASD to turn. Space to pause. Esc to quit.

## Record a 9:16 reel

```bash
python3 onyx_nibble.py --record
```

Outputs a 15-second 1080x1920 h264 MP4 with title, score and handle overlay.
